สำหรับแอดมินที่ส่งประกาศถึงพื้นที่ประสบภัย ใส่รหัสประกาศ (BROADCAST_KEY)

← กลับหน้าเว็บหลัก

ตั้งค่าระบบประกาศ (ครั้งเดียว)

  1. เปิด Google Sheet ใหม่ → ส่วนขยาย → Apps Script → วางโค้ดจากไฟล์ backend/broadcast.gs
  2. รูปเฟือง การตั้งค่าโปรเจกต์ → Script properties → เพิ่ม BROADCAST_KEY = รหัสที่แอดมินจะใช้
  3. Deploy → New deployment → Web app · Execute as: Me · Who has access: Anyone → คัดลอก URL ที่ลงท้าย /exec
  4. ใส่ URL ใน broadcast.js บรรทัด BROADCAST_URL แล้วขึ้นเว็บใหม่
